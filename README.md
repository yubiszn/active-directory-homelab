# Active Directory & Enterprise Identity Security Lab
Windows Server 2025 | Active Directory | PowerShell | IAM | Group Policy | VirtualBox

Project Overview

This project involves building and securing a simulated enterprise Windows environment using Windows Server 2025 and Active Directory.

The lab is designed to demonstrate practical skills in centralized identity management, user and group administration, authentication, access control, security policy enforcement, and PowerShell automation.

The environment will simulate an organization with multiple departments and more than 1,000 fictional employee accounts.

## Technologies & Tools

- Windows Server 2025
- Windows 11
- Oracle VirtualBox
- Active Directory Domain Services (AD DS)
- Domain Name System (DNS)
- Active Directory Users and Computers (ADUC)
- Group Policy Management (GPMC)
- PowerShell
- NTFS Permissions
- Role-Based Access Control (RBAC)

# Project Components

## 1. Enterprise Infrastructure
- Deploy a Windows Server 2025 virtual machine.
- Configure an Active Directory domain controller.
- Establish the adlab.local domain.
- Configure virtual networking and static IP addressing.
- Connect a Windows 11 client to the domain.

## 2. Identity and Access Management
- Create departmental Organizational Units (OUs).
- Automate the provisioning of 1,000+ fictional user accounts with PowerShell.
- Organize users into departmental security groups.
- Apply role-based access control and least-privilege principles.
- Demonstrate account administration and lifecycle management.

## 3. Security Policies and Access Control
- Configure Group Policy Objects (GPOs).
- Implement password and account lockout policies.
- Apply workstation restrictions and security configurations.
- Configure NTFS permissions for departmental resources.
- Test authentication and authorization from the client machine.

## 4. Security Analysis
- Develop an inventory of enterprise assets.
- Classify assets according to sensitivity and business criticality.
- Identify Active Directory and identity-related threats.
- Evaluate attack scenarios involving compromised accounts and excessive privileges.
- Document risks and recommended mitigations.
