
# Infrastructure Screenshots

This directory contains visual evidence of the initial infrastructure deployment and foundational configuration of the Active Directory and Enterprise Identity Security Lab.

The screenshots document the Windows Server 2025 environment, domain controller deployment, Active Directory management tools, DNS infrastructure, and initial network configuration.

### Documented Components

- Windows Server 2025 deployment and desktop environment.
- Server Manager and local server configuration.
- Active Directory Domain Services installation.
- Active Directory Users and Computers management console.
- Active Directory domain and forest configuration.
- DNS Manager and domain DNS namespace.
- Initial server hostname, IP addressing, and DNS configuration.

### Environment Details

| Component | Configuration |
|---|---|
| Operating System | Windows Server 2025 Standard Evaluation |
| Virtualization | Oracle VirtualBox |
| Server Hostname | ADServer |
| Active Directory Domain | adlab.local |

These screenshots establish the baseline infrastructure supporting subsequent identity management, access control, Group Policy, and security implementation.
