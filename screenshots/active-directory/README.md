# Active Directory Screenshots

This directory contains visual evidence of Active Directory administration and identity management activities performed within the simulated enterprise environment.

The screenshots will document the development of a centralized directory structure for managing employee identities, departmental organization, security groups, and domain resources.

### Documented Components

- Creation and organization of departmental Organizational Units (OUs).
- User account creation and administration.
- PowerShell-based bulk provisioning of fictional employee accounts.
- Departmental security group configuration and membership.
- Identity lifecycle management and account administration.
- Windows 11 client integration with the Active Directory domain.
- Domain authentication and identity verification.

### Security Concepts Demonstrated

- Centralized identity management.
- Role-Based Access Control (RBAC).
- Least-privilege access principles.
- Departmental account organization.
- Group-based access administration.

Screenshots will be added as each component is implemented and validated.
