# Group Policy & Security Configuration Screenshots

This directory contains visual evidence of Group Policy configuration and centralized security policy implementation within the Active Directory domain.

The screenshots will demonstrate how domain-managed policies are configured to establish consistent security settings and administrative controls across domain-joined Windows systems.

### Documented Components

- Group Policy Object (GPO) creation and configuration.
- Password complexity and password policy settings.
- Account lockout policy configuration.
- Workstation and desktop restrictions.
- Software execution and access restrictions.
- Group Policy application to domain-joined client systems.
- Verification of policy enforcement and configuration.

### Security Concepts Demonstrated

- Centralized security administration.
- Security policy enforcement.
- Standardized workstation configurations.
- Domain-level administrative controls.
- Consistent application of security requirements.

Screenshots will be added after implementation and verification of each policy.
