# Testing & Validation Screenshots

This directory contains visual evidence of testing and validation performed throughout the Active Directory and Enterprise Identity Security Lab.

The purpose of this documentation is to demonstrate that infrastructure components, directory services, authentication mechanisms, and security configurations function as intended.

### Documented Components

- Network connectivity between the domain controller and Windows 11 client.
- DNS resolution and domain name lookup verification.
- Active Directory domain connectivity.
- Windows 11 domain-joining process.
- Domain user authentication.
- User authorization and departmental resource access.
- Group Policy application and verification.
- NTFS permission and access control testing.
- Troubleshooting procedures and diagnostic command results.

### Validation Approach

Testing evidence will include the following wherever applicable:

- **Test Objective:** What functionality or security control is being evaluated.
- **Expected Result:** The behavior or outcome anticipated.
- **Observed Result:** What occurred during testing.
- **Validation Status:** Whether the test passed or requires further investigation.

This directory provides evidence of functional validation rather than simply documenting that configurations were created.
